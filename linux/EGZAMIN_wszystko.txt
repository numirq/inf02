#wyszukiwanie do przodu 

nano /etc/bind/named.conf.local

zone "mzsp.local" IN {
type master;
file "/etc/bind/db.mzsp.local";
};

tworzenie pliku konfiguracyjnego
cp /etc/bind/db.local /etc/bind/db.mzsp.local

edytujemy na linii SOA na 
ns1.mzsp.local. root.mzsp.local.

(serwer)    IN	A	(adres serwera)
(nazwa)     IN	A	(adres komputera)

aby sprawdzic czy dziala

ping serwer.mzsp.local
nslookup serwer.mzsp.local.

jak dziala tylko z komputera na serwer:
/etc/resolv.conf
nameserver 127.0.0.1 (lub adres serwera dns)


#wyszukiwanie wstecz

nano /etc/bind/named.conf.local

zone "10.168.192.in-addr.arpa" {
type master;
notify no;
file "/etc/bind/db.10.168.192";
};

tworzenie pliku konfiguracyjnego
cp /etc/bind/db.local /etc/bind/db.10.168.192

edytujemy na linii SOA na 
ns1.mzsp.local. root.mzsp.local.

1 (koncowka adresu serwera)    IN	PTR	(nazwa serwera).mzsp.local.
60 (koncowka adresu komputera)  IN	PTR	(nazwa komputera).mzsp.local.

aby sprawdzic czy dziala

nslookup 192.168.10.60 (ip komputera)
